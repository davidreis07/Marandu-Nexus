# Marandu Nexus

Plataforma Inteligente para Gestão de Incubadoras

## Objetivo

O Marandu Nexus é uma plataforma desenvolvida para apoiar a gestão da Incubadora Marandu, centralizando processos, acompanhamento de empresas, documentação, mentorias, indicadores e informações estratégicas em um único ambiente digital.
